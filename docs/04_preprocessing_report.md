# Предварительная обработка SMS

Обработан локальный корпус UCI из `data/processed/sms_raw.csv`. Исходный файл сохранён без изменений. Результат записан в `data/processed/sms_clean.csv` в UTF-8 со столбцами `id`, `text_raw`, `text_clean`, `label`. Для оставшихся записей сохранены исходные идентификаторы, порядок, тексты и метки.

Для дубликатов с одинаковой меткой сохраняется первая запись по порядку в исходном CSV. Групп с одинаковым `text_clean` и разными метками не обнаружено. При наличии такого конфликта скрипт исключает всю группу, поскольку исходные метки не позволяют выбрать одну из них.

## Воспроизведение

Из корня проекта с активированным виртуальным окружением выполните:

```powershell
python -m ml.preprocessing
python -m pytest -q -p no:cacheprovider
```

Если `sms_raw.csv` ещё не создан, сначала запустите `python ml/data/load_sms.py` по инструкции задания № 3.

Нормализация применяет NFKC, нижний регистр и замены по шаблонам, сохраняет кириллицу, казахские буквы, эмодзи и выделяет `!` и `?` отдельными токенами. Для удаления стоп-слов можно передать свой набор слов в нижнем регистре через параметр `stop_words`. При подготовке корпуса этот параметр не использовался. Распознавание телефонов и URL основано на текстовых шаблонах, поэтому нестандартные записи могут остаться нераспознанными, а похожие по формату идентификаторы могут быть приняты за телефоны.
