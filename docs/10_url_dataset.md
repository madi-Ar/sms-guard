## Артефакты сбора и исправление

Ниже доли/средние на очищенном корпусе до исправления представления и после него. Значения вычислены по реальным строкам, метки не менялись.

| HTTPS | 1.000000 | 0.486279 | 1.000000 | 0.486588 |

| Средняя длина URL | 27.228610 | 45.863791 | 23.229427 | 43.949316 |

Исправление включено: **True**. Выявлен сильный артефакт: все safe URL имеют HTTPS, www и не содержат пути/query. Минимальное исправление одинаково для обоих классов: удаление начального поддомена www и замена корневого пути '/' пустым. Содержательные пути и query сохраняются. Это представление для лексических признаков, а не утверждение, что два URL ведут на один сайт. Исходный URL сохранён отдельно. Нельзя удалять www, если это часть зарегистрированного домена (например, www.com). Различия по HTTPS и наличию содержательного пути остаются: подделывать схемы или добавлять выдуманные пути safe URL нельзя. Поэтому качество будущей модели может отражать способ сбора, а не реальную опасность.

## Подвыборка и разделение

Выбрано **50000** строк после очистки, `train_test_split(train_size=50000, stratify=label, random_state=42)`. Точные классы: `{'0': 28762, '1': 21238}`. Порядок после отбора — по source_id.

Группа — зарегистрированный домен через автономный tldextract (Unicode приводится к IDNA, завершающая точка убирается). Для IP — каноническая запись ipaddress. Если PSL не распознаёт суффикс, группа равна полному hostname. Используются публичные суффиксы; частные платформы могут образовывать более крупные консервативные группы.

Два `GroupShuffleSplit(n_splits=1, random_state=42)`: сначала test_size=0.30 для Validation+Test, затем test_size=0.50 внутри остатка. Seed не подбирался по результатам. Доли относятся к группам; точные доли строк и классов не гарантируются.

## Ограничения

Разметка UCI принимается без внешней проверки; датасет исторический, состав источников и формат классов различаются. Артефакты устранены лишь частично. Групповое разделение снижает утечку по домену, но не исключает похожие кампании на разных доменах. Стратифицированная подвыборка сохраняет классы, а GroupShuffleSplit может изменить их пропорции внутри частей. Канонизация www/корневого слеша изменяет лексические признаки и должна учитываться при будущем использовании модели. Дообучение, внешние проверки и URL-классификатор здесь отсутствуют.
