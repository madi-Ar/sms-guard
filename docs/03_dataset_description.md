## Формат и запуск

Файл `data/raw/SMSSpamCollection` извлечён из архива без изменения байтов. Он содержит метку и текст сообщения, разделённые табуляцией. Загрузчик строго проверяет UTF-8 и сохраняет исходный порядок и текст SMS. В `data/processed/sms_raw.csv` три столбца: `id` (номер строки с 1), `text` (исходный текст) и `label` (целая метка 0 или 1).

Из корня проекта с активированным окружением и установленными зависимостями выполните команду ниже. Если исходного файла нет, загрузчик скачает официальный ZIP UCI, проверит SHA-256 файла `SMSSpamCollection` и сохранит его в `data/raw/` без изменения байтов. Для первого запуска нужен интернет. При повторном запуске используется локальный файл.

Git хранит проверенный набор `custom_ru_kk.csv`. Исходный файл UCI и производный `sms_raw.csv` создаются локально.

```powershell
python ml/data/load_sms.py
```

## Искусственные SMS на русском и казахском

Файл `data/raw/custom_ru_kk.csv` содержит столбцы `id`, `text`, `label`, `language`. Метка 0 означает безопасный пример, 1 — пример мошеннического сообщения. По-русски составлено 100 примеров (50/50), по-казахски — 50 (25/25). Ссылки используют демонстрационную зону `.example`.

Тексты и предварительные метки сгенерированы с помощью ИИ (Codex). Тураров Алишер вручную проверил все 150 сообщений, подтвердил естественность формулировок и соответствие меток содержанию. Метка 0 (safe) обозначает безопасное сообщение, метка 1 (fraud) — мошенническое.
