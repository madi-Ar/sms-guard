# Отчёт о выполнении задания 2

**Тема проекта:** «Интеллектуальная система обнаружения мошеннических SMS-сообщений и подозрительных ссылок на основе методов искусственного интеллекта и машинного обучения».  
**Исполнители:** Арыстанов Мади, Тураров Алишер, группа SIS-2305.  
**Учебное заведение:** Международный университет информационных технологий.  
**Задание:** 2 — «Подготовка структуры проекта».

## 1. Цель работы

Создать воспроизводимую рабочую среду и минимальный каркас веб-приложения SMS Guard на Django, который можно запустить на Windows по инструкции из README.

## 2. Реализованные компоненты

1. Создан репозиторий с папками `config`, `apps/accounts`, `apps/analysis`, `apps/dashboard`, `ml`, `data/raw`, `data/processed`, `notebooks`, `templates`, `static`, `tests`, `docs`, `logs` и `scripts`.
2. Подготовлены `.gitignore` и `.env.example`: секреты и локальная база не фиксируются в Git. Скрипт `scripts/init_env.py` генерирует секретный ключ.
3. Указаны точные версии библиотек в `requirements.txt`; основная веб-часть — Django 5.2.8 и Django REST Framework 3.16.1.
4. Настроена главная страница (`/`) с `base.html`, Bootstrap 5, навигацией и адаптивной вёрсткой. Страница является заглушкой, как требует задание.
5. Создан служебный маршрут `GET /api/v1/health/` с ответом `{"status":"ok"}` (HTTP 200). Запрос POST отвергается (HTTP 405).
6. Создано логирование ошибок в `logs/app.log` с ротацией: максимальный размер 1 МБ, 5 резервных файлов.
7. Реализованы базовые автоматические тесты для проверки страницы и health-endpoint.
8. В `docs/` включены материалы выполненного задания №1.

## 3. Проверка

Проверки проводятся из корня проекта после создания `.env` и установки зависимостей:

```powershell
python manage.py check
python -m pytest -q
python manage.py migrate
python manage.py runserver
```

Ожидаемый результат на компьютере студента: `System check identified no issues`, успешные тесты, открывающаяся главная страница, JSON-ответ `{"status":"ok"}` по `/api/v1/health/`.

**Фактически выполненная статическая проверка (рабочая среда подготовки):**

- Синтаксический разбор 30 Python-файлов — успешно.
- Наличие 17 обязательных путей, проверка модулей и маршрута health — успешно.
- Проверка закреплённых версий 16 зависимостей — успешно.
- Проверка параметров ротации логов (1 МБ, 5 копий) — успешно.
- Генерация `.env` с криптографически случайным `DJANGO_SECRET_KEY` длиной 64 символа — успешно; повторный запуск не перезаписывает ключ.
- **Выполнение `python manage.py check`, `pytest` и HTTP-проверка Django остаются неподтверждёнными**: из рабочей среды не удалось скачать Django из-за отсутствия доступа к пакетному репозиторию. Их необходимо выполнить на Windows после установки зависимостей. Не следует отмечать эти проверки как пройденные до получения реального результата.
